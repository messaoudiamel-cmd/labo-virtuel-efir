    <h1>Mesures et incertitudes : évaluer, écrire et comparer un résultat</h1>
    <p class="prof">Professeure : <b>Mme Messaoudi</b> · EFIR · 2026-2027</p>
    <p class="pb"><span>Problématique :</span> quelle confiance accorder à une mesure, et comment l'écrire pour qu'un autre puisse la comparer ?</p>
    <ol class="parcours"><li><b>Répéter</b> une mesure : incertitude-type de type A</li><li><b>Lire</b> un instrument : incertitude-type de type B</li><li><b>Combiner</b> : incertitude d'une grandeur calculée (formule fournie)</li><li><b>Écrire</b> le résultat avec le bon nombre de chiffres</li><li><b>Comparer</b> à une valeur de référence : le z-score</li></ol>
    <details class="panel mots" open><summary>📖 Documents et données</summary>
<div class="doc"><b>Pourquoi une incertitude ?</b> Quand on mesure plusieurs fois la même grandeur, on n'obtient pas toujours la même valeur : c'est la <b>variabilité</b> de la mesure. On ne donne donc jamais une valeur seule, mais une valeur et son <b>incertitude-type u</b>, qui indique la dispersion des valeurs qu'on peut raisonnablement attribuer à la grandeur.</div>
<div class="doc"><b>Type A (mesures répétées).</b> Pour N mesures indépendantes x<sub>1</sub>, …, x<sub>N</sub> : on retient la moyenne x̄ et <b>u(x) = σ<sub>n−1</sub> / √N</b>, où σ<sub>n−1</sub> est l'écart-type expérimental (calculatrice : σx<sub>n−1</sub> ou s ; tableur : ECARTYPE.STANDARD).</div>
<div class="doc"><b>Type B (un seul mesurage).</b> Lecture sur une graduation : <b>u = 1 graduation / √12</b>. Tolérance ou précision ± a indiquée par le fabricant (verrerie, appareil) : <b>u = a / √3</b>.</div>
<div class="doc"><b>Grandeur calculée.</b> L'incertitude-type se calcule avec une <b>formule fournie</b> par l'énoncé, par exemple pour G = x × y / z : u(G)/G = √[(u(x)/x)² + (u(y)/y)² + (u(z)/z)²].</div>
<div class="doc"><b>Écriture du résultat.</b> u s'arrondit <b>par excès</b> à un chiffre significatif (deux au plus) ; la valeur s'arrête à la <b>même décimale</b> que u. On écrit G = valeur unité ; u(G) = … unité.</div>
<div class="doc"><b>Comparaison à une référence.</b> <b>z = |G<sub>mes</sub> − G<sub>réf</sub>| / u(G)</b>, calculé avec les valeurs non arrondies. Si z ≤ 2, le résultat est compatible avec la référence ; sinon, on cherche une cause (erreur systématique, protocole, incertitude sous-estimée).</div>
</details>
    <details class="panel mots" id="aide"><summary>❓ Aide</summary><dl><dt>Chiffres significatifs</dt><dd>Les zéros à gauche ne comptent pas : 0,0508 a 3 chiffres significatifs. Pour l'arrondir par excès à 1 chiffre : 0,06.</dd>
<dt>Puissances de dix</dt><dd>Écrivez valeur et incertitude avec la même puissance de dix : c = 4,2 × 10<sup>3</sup> J·kg<sup>−1</sup>·°C<sup>−1</sup> ; u(c) = 0,1 × 10<sup>3</sup> J·kg<sup>−1</sup>·°C<sup>−1</sup>.</dd>
<dt>Valeur aberrante</dt><dd>Une valeur très éloignée des autres, due à une erreur de manipulation identifiée, peut être écartée avant le calcul, en le signalant.</dd>
<dt>Outil</dt><dd>La <a href="#" onclick="parent.location.hash='outil/calculatrice';return false">calculatrice scientifique</a> du labo calcule aussi une incertitude-type et un z-score.</dd></dl></details>

(function () {
  const $ = s => document.querySelector(s), fr = x => String(x).replace(".", ",");
  const nombres = t => (t || "").replace(/;/g, " ").split(/\s+/).map(v => v.trim().replace(",", ".")).filter(v => v !== "").map(Number);
  /* arrondi par excès de u à un chiffre significatif, et nombre de décimales correspondant */
  function arrondiU(u) { if (!(u > 0)) return { u: 0, d: 0 }; const p = Math.floor(Math.log10(u)), q = Math.pow(10, p); let r = Math.ceil(u / q - 1e-9) * q; if (r >= 10 * q) { r = 10 * q; }
    const d = Math.max(0, -Math.floor(Math.log10(r))); return { u: r, d }; }
  function calcule() {
    const X = nombres($("#inc-val").value), U = $("#inc-unite").value.trim(), out = $("#inc-out"), sp = U ? " " + U : "";
    if (X.length < 2 || X.some(isNaN)) { out.innerHTML = '<span class="ko">Entrez au moins deux nombres.</span>'; return; }
    const N = X.length, m = X.reduce((a, b) => a + b, 0) / N, s = Math.sqrt(X.reduce((a, b) => a + (b - m) ** 2, 0) / (N - 1)), u = s / Math.sqrt(N), A = arrondiU(u);
    let h = `N = ${N} ; moyenne = ${fr(+m.toPrecision(8))}${sp} ; σ<sub>n−1</sub> = ${fr(+s.toPrecision(4))}${sp} ; u = σ<sub>n−1</sub> / √N = ${fr(+u.toPrecision(4))}${sp}<br>`;
    h += `<span class="res">Résultat : ${fr(m.toFixed(A.d))}${sp} ; u = ${fr(A.u.toFixed(A.d))}${sp}</span>`;
    const r = nombres($("#inc-ref").value)[0];
    if (r !== undefined && !isNaN(r)) { const z = u > 0 ? Math.abs(m - r) / u : Infinity;
      h += `<br>z = |${fr(+m.toPrecision(6))} − ${fr(r)}| / ${fr(+u.toPrecision(3))} = ${fr(z.toFixed(2))} : ` + (z <= 2 ? '<span class="ok">z ≤ 2, résultat compatible avec la référence.</span>' : '<span class="ko">z > 2, résultat non compatible : cherchez une erreur systématique.</span>'); }
    out.innerHTML = h; }
  function calculeB() { const a = nombres($("#inc-b-a").value)[0], k = +$("#inc-b-type").value, out = $("#inc-b-out");
    if (!(a > 0)) { out.innerHTML = '<span class="ko">Entrez une valeur positive.</span>'; return; }
    const u = a / Math.sqrt(k), A = arrondiU(u); out.innerHTML = `u = ${fr(a)} / √${k} = ${fr(+u.toPrecision(3))} <span class="res">u ≈ ${fr(A.u.toFixed(A.d))} (arrondie par excès)</span>`; }
  $("#inc-go").addEventListener("click", calcule); $("#inc-b-go").addEventListener("click", calculeB);
})();
